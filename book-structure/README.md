## Plan
- 169 study units (one card per passage or verse) with six questions each: about 1014 questions, plus the closing unit.
- Each card: the text in Devanagari, word split, Hindi, English, explanation, memory aids and computed metre where it applies.
- Writer model: Sonnet 5.5. Every draft chunk and every authored batch gets an independent review. This is a large job and uses a lot of usage; it can be run chapter by chapter.
- No translation was supplied, so the Hindi and English are written by the AI writer model and are marked "AI-written, AI-reviewed, not yet checked by a scholar".

## Excluded
- Sutrasthana chapter 6 onwards and the other sthanas (outside the first part).
- The edition's footnotes and variant readings (kept as source notes for reviewers; not tested).
- Chapter colophons.

## Not covered
Recitation, pronunciation, commentary traditions (Dalhana is not in the e-text), and any clinical or surgical practice. Questions test words, forms, order and what the text says.
